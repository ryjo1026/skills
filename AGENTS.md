# Agent context

Public [Agent Skills](https://agentskills.io) repo (`ryjo1026/skills`). Each skill is `<name>/SKILL.md` at the repo root, `<name>` lowercase-hyphen and matching the directory.

- **Public audience — nothing work-related or private.** This repo is cloned to every machine.
- **Direct commits to `main` are fine here** — no branch or PR needed. Use conventional-commit subjects (`feat(worktree): …`).
- Consumed by editing the source repo; installed copies elsewhere are symlinks into a clone, so a push + re-pull propagates changes.
